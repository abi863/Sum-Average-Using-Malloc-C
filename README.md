# Sum and Average Using malloc() in C

## Description
This program dynamically allocates memory for an array of integers using `malloc()`, reads the elements, calculates their sum and average, and releases the allocated memory.

## Concepts Used
- Dynamic memory allocation
- `malloc()`
- Pointers and arrays
- `for` loops
- Sum and average calculations
- `free()`

## How to Run
```bash
gcc sum_average_malloc.c -o sum_average_malloc.exe
./sum_average_malloc.exe
```

## Language
C
